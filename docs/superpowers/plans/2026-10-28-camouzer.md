# Camouzer Implementation Plan

> **For agentic workers:** Implement task-by-task. Steps use checkbox syntax.

**Goal:** Ship a GPL-2 repo with a Windows MF virtual camera named Camouzer plus a Python library that captures the Logitech webcam, reduces facial redness, and feeds NV12 frames into that device for Discord.

**Architecture:** Python producer → Global shared memory → CamouzerSource.dll (IMFMediaSource) ← CamouzerHost (MFCreateVirtualCamera).

**Tech Stack:** C++17 / CMake / Windows SDK 10.0.26100+, Python 3.11, OpenCV, NumPy.

## Global Constraints

- No OBS, no Unity Capture.
- Windows 11 build ≥ 22000 (target 26200).
- Device friendly name: `Camouzer`.
- Native stack adapted from BestCam (GPL-2); keep LICENSE.
- Document kernel-mode driver path; do not implement it in v1.
